# aiarmada/filament-rewards

Filament v5 admin adapter for [aiarmada/rewards](../rewards/README.md): programs, awards, appeals, funding, payees, payouts, benefit items/grants, recoveries, and the fraud queue.

Register `FilamentRewardsPlugin::make()` on your panel. See [CONTEXT.md](CONTEXT.md) and [docs/01-overview.md](docs/01-overview.md) to start.
