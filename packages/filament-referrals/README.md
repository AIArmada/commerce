# aiarmada/filament-referrals

Filament v5 admin adapter for [aiarmada/referrals](../referrals/README.md): referral programs, addressed invites, frozen rewards, lifecycle actions, and owner-scoped statistics.

Register **FilamentReferralsPlugin::make()** on a panel. See [CONTEXT.md](CONTEXT.md) and [docs/01-overview.md](docs/01-overview.md) to start.
